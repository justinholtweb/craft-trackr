# Plugin Store promo images

Marketing images for the Trackr listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-trackr](https://justinholt.com/plugins/craft-trackr).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `trackr-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#3f4ea8`, amber `#f0a63c` for the in-transit accent, Jersey 20 for
display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — route, parcel and pin only, no frame. The full icon's frame is a solid rounded
  rect that reads as a hard-edged box at watermark scale, which is why the frame is stripped rather
  than the whole icon being faded further. The pin is drawn with `fill-rule: evenodd` so its centre
  stays open, the way the icon's indigo dot is.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## Traps

- **The wordmark gradient has to start light.** The plugin accent `#3f4ea8` is barely lighter than
  the slide background, so a gradient that begins on it renders an almost invisible title. The
  `.gradient-text` ramp starts at `#7d8ce0` for that reason — don't "correct" it back to the brand
  indigo.
- **A bare `<span>` is inline.** `.meter .fill` needs `display: block`, or its `width` and `height`
  are silently ignored and the progress bar renders as an empty track.
- **`.points` needs its `max-width`.** The right-hand `.panel` starts at x=900; without the cap, a
  long bullet runs underneath it and the collision only shows up in the PNG.
